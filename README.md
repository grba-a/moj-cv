# moj-cv — arhiva

CV je preseljen na **https://petargrbic.com/cv** i živi u repozitoriju
[`grba-a/portfolio-nextjs`](https://github.com/grba-a/portfolio-nextjs)
(`src/app/cv/page.tsx`), gdje dijeli podatke s portfolijem — projekte,
certifikate i kontakt — pa se dvije stranice ne mogu razići.

Ovaj repo se zadržava samo zbog trajnog preusmjerenja (`vercel.json`),
da poveznice koje su već negdje poslane nastave raditi.

**Ovdje se više ne uređuje ništa.** Izmjene idu u `portfolio-nextjs`.
